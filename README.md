# Studio H2O — Website

Static English-language website for Studio H2O Oy.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload the **contents of this folder** to the repository root (so `index.html` is at the top level).
3. Under **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/ (root)` and save.
4. Wait for GitHub Pages to provide the public URL.

You can also open `index.html` locally. Images, CSS and JavaScript use relative paths. Google Fonts requires an internet connection; fallback fonts are included.

## Folder layout

- `index.html` — homepage
- `assets/css/style.css` — layout and typography
- `assets/js/main.js` — simple navigation behavior
- `assets/images/` — bundled local images

This package is based on the latest Studio H2O website revision.
